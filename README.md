# 城市地下综合管廊运行维护管理平台

面向管廊主体台账、入廊管线登记、廊内环境监测、通风排水消防、结构沉降与渗漏处置、巡检检修与隐患整改、入廊作业审批和运维值班的一体化城市地下综合管廊运行维护管理工作台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `urban-utility-tunnel:entries:v2` 这一项（老账套
  `urban-utility-tunnel:entries` 在升级时原样保留不覆盖），或调用 `resetModule(模块)`。

## 巡检治理口径（排班 / 隐患 / 派工 / 往期单据）

治理逻辑全部在 `frontend/src/data/governance.ts`（纯计算）与
`frontend/src/api/governance-service.ts`（落账动作），页面只读派生结果：

- **排班视图**：横着一周（周一起）、竖着班组，格子里是路线与计划日期，点格子回巡检明细并带筛选。
  明细条数、排班格子数、概览同日分布图共用 `patrolSnapshot()` 一份口径，不允许出现两个数。
- **去重**：先按巡检编号去重（同编号留 id 最小），再按“巡检路线 + 计划日期”去重
  （班组明确优先、问题数多优先）。被并记录不删除，挂“已并入”痕迹，明细页可勾选查看。
- **回填与推定**：计划日期缺失按完成时间回填（兼容带时分的旧格式）；早年无班组先按全量
  “路线 → 最常归属班组”投票推定，投票不出结果时按路线名稳定哈希兜底，同一历日结果可复现。
  推定/回填只打标记，不回写原始记录。
- **隐患同步**：发现问题数大于 0 的巡检任务按来源巡检编号在隐患台账幂等挂“待整改”；
  已存在的只更新问题数，不改状态结论（既有结论一律不改写）。
- **派工清单**：同一来源 + 同一动作只落一条，连续重复触发并入该条轨迹；关键条目页与
  派工清单页的“处理意见”都走 `saveOpinion()`，两边同一份。
- **往期单据**：电子按抄表周期搬入，早期纸面按扫描件编号建账（`legacyDocs` 数据集）。
- **超时断线**：`reportPatrolIssue` 遇超时/断线自动重试一次，仍失败则两次原因都记入失败台账、
  不落半截账，网络恢复后在原处重试。关键条目页可切换“正常/超时/断线”演示。
- **账套升级**：本地存储升级为 v2，v1 原始记录整体搬迁保留；新巡检/隐患/能耗以新种子为准。
